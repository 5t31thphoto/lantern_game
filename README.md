# Lantern — The Long Night v7

A focused, cozy, local-first browser game centered on making and releasing paper lanterns.

## Run

Open `index.html` in a modern browser, or publish the folder as a static GitHub Pages site.

No server, account, API, CDN, package manager, runtime dependency, analytics, or build step is required.

## Core loop

Wander → gather → make → write → assemble → light → launch → watch the lantern recede → return to the workshop → make another.

The player's sky is a persistent visual history of lanterns released. Materials and progression exist to motivate the ritual without turning it into a grind or a virtual-pet obligation.

## Muse

The main game remains fully playable without Muse. The optional quiet-flight experience is designed to use Muse as subtle feedback rather than pretending consumer EEG directly measures emotion. A future browser BLE adapter can feed normalized quality/steadiness values into the visual layer.

## Local-first

All state is kept in `localStorage`. Save export/import is local JSON. Nothing is transmitted by the game.

## Therapeutic design boundary

The fictional game world is not presented as counseling, diagnosis, trauma treatment, or memory recovery. Therapeutic mechanisms are embedded in gameplay: noticing, returning attention, gentle action, connection, continuing bonds, meaning, restoration, and tolerating difficult states without making distress itself a failure condition.
